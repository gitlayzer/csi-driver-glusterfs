## 背景（必读）
CSI v1.13 **已删除** `VOLUME_CONDITION`：`NodeServiceCapability_RPC` 的枚举 4 与 `NodeGetVolumeStatsResponse` 的字段 2 都是 reserved。
取代它的是 alpha 的 `NodeGetVolumeHealth`（能力 `GET_VOLUME_HEALTH`）。决策 D-18：
- `NodeGetVolumeStats` 只返回 statfs 用量；挂载失效时返回 `Internal`。
- `NodeGetVolumeHealth` 对失效挂载上报 `INACCESSIBLE`。
- **不得**使用原始枚举值 4，**不得**用 protobuf unknown fields 伪造旧字段。

两个 RPC 都是只读的：**不加 in-flight 锁**（监控调用不应被 Stage/Publish 挡成 Aborted），也不查集群配置。

## 设计

### `pkg/mounter`：`MountState` 与 `VolumeMountState`
```go
// MountState describes what is mounted at a path, as far as one volume is concerned.
type MountState int

const (
	// MountStateNotMounted: the path does not exist or is not a mount point.
	MountStateNotMounted MountState = iota
	// MountStateMounted: the path is a glusterfs mount of the requested volume
	// (the FUSE mount itself or a bind mount of it).
	MountStateMounted
	// MountStateMismatch: the path is a mount point of something else (another
	// volume or subdirectory, another file system type, or a mount point that
	// the mount table does not list).
	MountStateMismatch
	// MountStateCorrupted: the path is a mount point whose file system stopped
	// responding (ENOTCONN and the other errors of isCorrupted).
	MountStateCorrupted
)

// String returns "NotMounted", "Mounted", "Mismatch", "Corrupted", or "MountState(<n>)".
func (s MountState) String() string
```
`Mounter` 接口新增（同时在接口注释里说明它供 NodeGetVolumeStats / NodeGetVolumeHealth 使用）：
```go
// VolumeMountState reports what is mounted at target with respect to the
// glusterfs volume volume[/subdir]. err is non-nil only when the state cannot
// be determined (invalid arguments, unreadable mount table, a stat failure
// other than "does not exist" and "corrupted").
VolumeMountState(target, volume, subdir string) (MountState, error)
```
实现：
1. `validatePath("target", target)`；`volumeid.ValidateName("volume", volume)`；`subdir` 非空时 `volumeid.ValidateName("subdir", subdir)`；
   失败用 `specErrf` 返回（`errors.Is(err, ErrInvalidSpec)`）。
2. `mounted, err := m.IsMountPoint(target)`：
   - `errors.Is(err, fs.ErrNotExist)` → `MountStateNotMounted, nil`
   - `errors.Is(err, ErrCorruptedMount)` → `MountStateCorrupted, nil`
   - 其他 err → `0, err`（已带上下文，原样返回）
   - `!mounted` → `MountStateNotMounted, nil`
3. `entry, found, err := m.findMountEntry(target)`：err → 返回；`!found` → `MountStateMismatch`。
4. `slices.Contains(glusterfsTypes, entry.Type) && volumePath(entry.Device) == want` → `MountStateMounted`，否则 `MountStateMismatch`。
   `want = "/" + volume`，subdir 非空时再加 `"/" + subdir`（与 `BuildMountArgs` 的 source 一致）。server 部分不比较（故障转移后可能是任一 server）。

说明：Linux 上 bind mount 在 `/proc/mounts` 中显示原 FUSE 挂载的 device 与 `fuse.glusterfs` 类型，所以 Publish 的 target 同样判为 Mounted。
**`mount.FakeMounter` 记录 bind mount 时 Type 为 `""`**，测试中需要在 bind 之后把对应 `fake.MountPoints[i].Type` 改成 `"fuse.glusterfs"`
来模拟 Linux（写注释说明）。**生产代码不得为此放宽类型检查。**

### `pkg/driver/volumestats.go`
```go
// fsStats are the statfs numbers of a file system. Every field is >= 0.
type fsStats struct {
	totalBytes, availableBytes, usedBytes int64
	totalInodes, freeInodes, usedInodes   int64
}

// statsFromStatfs converts raw statfs numbers. bsize is the block size in bytes.
// used = blocks - bfree (0 when bfree > blocks); bytes = blocks * bsize.
// A product or value that does not fit into int64 is clamped to math.MaxInt64,
// so no field is ever negative (the CSI spec forbids negative values).
func statsFromStatfs(blocks, bfree, bavail, bsize, files, ffree uint64) fsStats
```
`nodeService` 新增字段（`driver.go` 的 New 里初始化为 `statFS`）：
```go
// statFS reads the file system statistics of a path; a field so that tests
// can simulate statfs results and failures.
statFS func(path string) (fsStats, error)
```

#### 平台实现
- `statfs_linux.go`（`//go:build linux`）和 `statfs_darwin.go`（`//go:build darwin`）：
  ```go
  func statFS(path string) (fsStats, error) {
  	var st syscall.Statfs_t
  	if err := syscall.Statfs(path, &st); err != nil {
  		return fsStats{}, &os.PathError{Op: "statfs", Path: path, Err: err}
  	}
  	return statsFromStatfs(st.Blocks, st.Bfree, st.Bavail, <bsize as uint64>, st.Files, st.Ffree), nil
  }
  ```
  Linux 的 `Bsize` 是 int64：负值视为 0（`if st.Bsize > 0 { bsize = uint64(st.Bsize) }`）；darwin 的 `Bsize` 是 uint32，直接转换。
  块大小用 `Bsize`（与 kubelet 的 `fs.Info` 一致）。若 gosec 报 G115，用上面的显式判断消除，不要加 `nolint`。
- `statfs_other.go`（`//go:build !linux && !darwin`）：返回 `fmt.Errorf("statfs %q: %w", path, errors.ErrUnsupported)`。

#### NodeGetVolumeStats
1. `volume_id` 空 → InvalidArgument；`volume_path` 空 → InvalidArgument。
2. `decodeVolumeID` → NotFound。
3. `volume_path` 不是绝对路径或不干净（`filepath.Clean(p) != p`）→ **NotFound**（`volume %s does not exist at %q`）。
   理由写进注释：规范对这个 RPC 只定义了 NotFound（"does not exist on specified volume_path"），一个非法路径不可能是卷所在的位置；
   csi-sanity 用 `"some/path"` 断言 NotFound。
4. `staging_target_path` **不使用、不校验**（OPTIONAL，统计只看 volume_path），注释说明。
5. `ctxStatus(ctx)`。
6. `state, err := s.mounter.VolumeMountState(volumePath, id.Volume, id.Subdir)`：
   | 结果 | 返回 |
   |---|---|
   | err != nil | Internal（`check volume %s at %q: %v`） |
   | NotMounted | NotFound（`volume %s is not mounted at %q`） |
   | Mismatch | NotFound（`volume %s is not mounted at %q, another file system is`） |
   | Corrupted | Internal（`mount of volume %s at %q is corrupted; NodeGetVolumeHealth reports it`） |
   | Mounted | 继续 |
7. `st, err := s.statFS(volumePath)`：
   - `errors.Is(err, fs.ErrNotExist)` → NotFound（挂载在检查后被卸载的竞态）；
   - 损坏类错误（用 `mount.IsCorruptedMnt(err)` 或 `errors.Is` 匹配 `syscall.ENOTCONN`/`ESTALE`/`EIO`/`EHOSTDOWN`）→ Internal（同上 corrupted 信息）；
   - 其他 → Internal（`statfs %q: %v`）。
8. 响应 `Usage`：
   - 总是有 `{Unit: BYTES, Total: totalBytes, Available: availableBytes, Used: usedBytes}`；
   - `totalInodes > 0` 时追加 `{Unit: INODES, Total: totalInodes, Available: freeInodes, Used: usedInodes}`，否则省略（规范允许 inode 不可用时省略）。

### `pkg/driver/volumehealth.go`：NodeGetVolumeHealth
1. `volume_id` 空 → InvalidArgument。
2. `decodeVolumeID` → NotFound。
3. `staging_target_path`、`volume_publish_path` 非空时各自 `validatePath` → InvalidArgument（规范："If not empty, it MUST be an absolute path"）。
4. `ctxStatus(ctx)`。
5. 依次检查非空的 staging 路径、publish 路径：`VolumeMountState(path, id.Volume, id.Subdir)`；任何一个 err → **整个 RPC** Internal。
   状态映射为健康条目（`csi.VolumeHealth_VolumeHealthEntry`）：
   | 状态 | Status | Reason |
   |---|---|---|
   | Mounted | 无条目 | — |
   | Corrupted | `INACCESSIBLE` | `MountCorrupted` |
   | NotMounted | `INACCESSIBLE` | `NotMounted` |
   | Mismatch | `INACCESSIBLE` | `VolumeMismatch` |
   - Message：`staging target path "<p>" ...` / `publish path "<p>" ...`，一句话说明。
   - 规范要求同一卷不得出现两个 (status, reason) 相同的条目：两个路径同一 reason 时**合并为一个条目**，Message 用 `"; "` 连接，
     顺序 staging 在前。条目顺序按首次出现。
6. 两个路径都为空：不调用 mounter，返回空的 `HealthStatuses`（规范："An empty list means no adverse health condition is known"）。
   注释说明：插件无状态，不知道卷挂在哪里。
7. 响应 `VolumeHealth{VolumeId: req.VolumeId, HealthStatuses: ...}`，VolumeId 必须回显（csi-sanity 断言）。

## 测试（表驱动，断言行为）
1. `pkg/mounter` `TestVolumeMountState`（真实 `mount.FakeMounter`）：
   - 路径不存在 → NotMounted；存在但未挂载 → NotMounted；
   - `MountGlusterfs` 挂载 `vol` 后查 `vol` → Mounted；查 `vol` + subdir `a` → Mismatch；查 `other` → Mismatch；
   - 挂载 `vol` 子目录 `a` 后查 `vol`/`a` → Mounted，查 `vol` → Mismatch；
   - 预置 `MountPoints` 为 `{Device: "g2:/vol", Type: "fuse.glusterfs"}`（不同 server）→ Mounted；`{Device: "nfs:/vol", Type: "nfs"}` → Mismatch；
   - bind mount（`BindMount` 后把该条目 Type 改为 `fuse.glusterfs`）→ Mounted；
   - `MountCheckErrors[target] = syscall.ENOTCONN` → Corrupted，err 为 nil；
   - List 失败（嵌入 `*mount.FakeMounter` 覆盖 `List` 返回错误的测试类型）→ err 包含原因；
   - 非法参数（相对 target、volume 含 `/`、subdir 为 `..`）→ `errors.Is(err, ErrInvalidSpec)`；
   - `MountState.String()` 四个值与越界值。

   `files` 大于 `MaxInt64` → 夹到 `MaxInt64`；`files == 0` → 三个 inode 字段为 0；任何用例所有字段 ≥ 0。
3. `TestStatFS`（linux/darwin 上运行；在 `statfs_test.go` 加 `//go:build linux || darwin`）：对 `t.TempDir()` 返回 `totalBytes > 0`、

   VolumeMountState 返回错误 → Internal；statFS 返回 `&os.PathError{Err: syscall.ENOENT}` → NotFound，`syscall.ENOTCONN` → Internal，
